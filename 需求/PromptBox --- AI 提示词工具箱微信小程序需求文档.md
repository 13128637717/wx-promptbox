# PromptBox --- AI 提示词工具箱微信小程序需求文档（PRD）

-   **版本：** V1.0
-   **日期：** 2026-10-30
-   **产品类型：** 效率工具 / 提示词管理
-   **运行平台：** 微信小程序
-   **技术方案：** 微信原生小程序 + 本地 JSON + 本地存储
-   **核心约束：** 不依赖自建服务器、不使用微信云开发、不调用大模型 API

------------------------------------------------------------------------

## 一、产品概述

### 1.1 产品定位

PromptBox 是一款面向 AI
用户的提示词管理与复用工具，帮助用户快速查找、编辑、收藏和复制高质量提示词。

用户无需注册登录，也不需要绑定 AI
平台账号，即可使用小程序内置的提示词资源。

### 1.2 产品目标

1.  提供丰富、分类清晰的提示词库。
2.  帮助用户快速找到适合自己的提示词。
3.  支持变量替换，降低提示词使用门槛。
4.  支持收藏和自定义提示词管理。
5.  支持本地数据备份与恢复。
6.  为后续提示词模板商业化预留扩展能力。

### 1.3 目标用户

  用户类型       核心需求
  -------------- ------------------------------
  普通 AI 用户   快速找到好用的提示词
  程序员         代码生成、代码审查、Bug 排查
  自媒体创作者   文章、标题、文案生成提示词
  职场人员       PPT、Excel、总结、办公提示词
  AI 绘画用户    图片生成描述词
  AI 学习者      学习计划、知识整理、问题分析

## 三、详细功能需求

### 3.1 首页发现

**优先级：P0，第一版必须实现。**

页面目标：用户打开小程序后，能够快速找到想要的提示词。

  编号   功能         需求描述
  ------ ------------ --------------------------
  H001   搜索框       输入关键词搜索提示词
  H002   搜索历史     保存最近搜索关键词
  H003   热门分类     展示常用提示词分类
  H004   今日推荐     展示精选提示词
  H005   热门提示词   按本地配置排序展示
  H006   专题合集     展示不同场景的提示词合集
  H007   最近使用     展示最近复制的提示词

首页建议展示顺序：

1.  顶部品牌区域。
2.  提示词搜索框。
3.  分类快捷入口。
4.  今日精选。
5.  热门提示词。
6.  专题合集。
7.  最近使用。

**搜索规则：**

-   支持标题搜索。
-   支持提示词正文搜索。
-   支持标签搜索。
-   支持分类筛选。
-   搜索结果展示收藏状态。
-   无搜索结果时展示空状态页面。

### 3.2 分类模块

**优先级：P0，第一版必须实现。**

第一版内置 10 个分类：

  分类 ID      分类名称   示例内容
  ------------ ---------- ----------------------
  `writing`    AI 写作    文章、标题、文案
  `coding`     AI 编程    代码生成、Bug 排查
  `drawing`    AI 绘画    图片描述、风格设计
  `video`      AI 视频    分镜、脚本、视频描述
  `office`     AI 办公    PPT、Excel、总结
  `media`      自媒体     选题、运营、涨粉
  `learning`   AI 学习    学习计划、知识整理
  `business`   商业运营   市场分析、商业策划
  `analysis`   数据分析   数据解读、报告
  `general`    通用工具   角色设定、日常助手

分类页面要求：

-   展示分类图标、名称、简介和提示词数量。
-   点击分类进入分类详情。
-   分类详情展示对应提示词列表。
-   支持按热度、最新排序。
-   支持标签筛选。

### 3.3 提示词详情

**优先级：P0，第一版必须实现。**

  编号   功能       说明
  ------ ---------- ------------------
  D001   标题       展示提示词名称
  D002   描述       展示用途说明
  D003   正文       展示完整提示词
  D004   分类       展示所属分类
  D005   标签       展示相关标签
  D006   收藏       添加或取消收藏
  D007   复制       一键复制完整内容
  D008   编辑       进入提示词编辑器
  D009   使用示例   展示填写示例
  D010   相似推荐   推荐同分类提示词

复制成功后：

-   提示复制成功。
-   自动写入最近使用记录。
-   更新本地复制次数。
-   用户可以前往其他 AI 平台粘贴使用。

### 3.4 提示词编辑器

**优先级：P0，第一版必须实现。**

这是产品的核心差异化功能。

支持变量格式：

``` text
{{变量名称}}
```

示例：

``` text
你是一名资深的{{职业}}。

请帮我完成以下任务：

任务类型：{{任务类型}}

具体内容：
{{具体内容}}

请按照以下结构输出：
1. 问题分析
2. 解决方案
3. 实施步骤
4. 最终结果
```

功能要求：

  功能           说明
  -------------- ----------------------------
  自动识别变量   解析提示词中的变量
  动态表单       根据变量自动生成输入框
  默认值         支持设置变量默认值
  实时预览       根据用户输入动态生成提示词
  手动编辑       支持直接修改最终内容
  重置           恢复变量默认值
  一键复制       复制替换后的完整提示词
  保存模板       保存为个人提示词

业务规则：

1.  自动识别 `{{变量名称}}`。
2.  相同名称的变量视为同一个变量。
3.  未填写变量时使用默认值。
4.  没有默认值的必填变量应提示用户填写。
5.  替换后不得丢失原始提示词内容。
6.  变量替换结果应支持用户手动修改后再复制。

### 3.5 我的收藏

**优先级：P0，第一版必须实现。**

-   展示所有收藏的提示词。
-   支持按分类筛选。
-   支持关键词搜索。
-   支持取消收藏。
-   支持按收藏时间排序。
-   自定义收藏夹作为 P1 功能。

### 3.6 我的提示词

**优先级：P1，第二阶段实现。**

用户可以创建和管理自己的提示词。

-   新增提示词。
-   修改提示词。
-   删除提示词。
-   设置提示词标题。
-   设置分类。
-   设置标签。
-   设置提示词正文。
-   设置变量和默认值。
-   收藏自己的提示词。

用户自定义内容与系统内置内容必须分开保存，不能直接修改系统原始 JSON
数据。

### 3.7 使用记录

**优先级：P1，第二阶段实现。**

-   记录最近复制的提示词。
-   记录复制时间。
-   支持再次复制。
-   支持删除单条记录。
-   支持清空历史记录。
-   默认保留最近 50 条记录。

说明：小程序只能记录用户在小程序内执行的复制行为，不能判断用户是否已经在其他
AI 平台成功使用。

### 3.8 个人中心

**优先级：P1，第二阶段实现。**

展示内容：

-   本地昵称或默认头像，不强制登录。
-   我的收藏数量。
-   我的提示词数量。
-   最近复制数量。
-   数据管理。
-   使用帮助。
-   关于我们。
-   隐私政策。

### 3.9 数据管理

**优先级：P1，第二阶段实现。**

支持：

-   导出收藏数据。
-   导出个人提示词。
-   导入 JSON 文件。
-   数据格式校验。
-   重复数据处理。
-   导入结果统计。

实现时需要使用小程序文件管理器
API，并考虑不同微信版本和系统环境的兼容性。导入失败时应保留原有数据，不得因解析失败覆盖用户数据。

### 3.10 分享功能

**优先级：P2，后续迭代。**

-   将提示词标题、简介和正文生成分享卡片。
-   支持保存图片。
-   支持小程序页面分享。
-   分享卡片不应默认暴露用户私人提示词，生成前需由用户主动选择。

### 3.11 提示词版本管理

**优先级：P2，后续迭代。**

-   保存提示词修改版本。
-   查看历史版本。
-   对比不同版本内容。
-   恢复指定版本。

## 六、技术实现方案

### 6.1 技术选型

  功能             技术实现
  ---------------- ------------------------------------
  小程序框架       微信原生小程序
  开发语言         JavaScript
  内置提示词数据   本地 JSON
  分类配置         本地 JSON
  搜索             JavaScript 本地过滤
  收藏管理         `wx.setStorageSync` 等本地存储 API
  使用记录         本地存储
  变量替换         JavaScript 字符串处理
  一键复制         `wx.setClipboardData`
  图片生成         Canvas
  数据导入导出     小程序文件管理器 API

### 6.2 本地运行原则

-   核心功能不依赖网络。
-   不接入微信云开发。
-   不搭建后端服务器。
-   不调用 OpenAI、DeepSeek 等模型 API。
-   不强制用户登录。
-   不实现跨设备同步。
-   不将用户数据上传到第三方服务。

### 6.3 数据限制与异常处理

-   本地存储容量有限，应控制单条记录和总数据量。
-   用户卸载小程序、清理数据或更换设备可能导致本地数据丢失。
-   应提供数据导出和恢复能力。
-   JSON 导入前必须校验格式、字段和数据版本。
-   导入失败不得破坏已有数据。
-   对空列表、异常数据和复制失败提供明确提示。
