# 搜索图标不再被裁切

| 项 | 值 |
|----|-----|
| 日期 | 2026-11-03 |
| 时间 | 14:39 |
| 概要 | 搜索图标不再被裁切 |
| 关联计划 | 无 |

## 背景与目标

首页搜索框里的放大镜左边被切掉，圆环不完整。

## 方案概述

把放大镜整体内收，圆环不再贴着图标容器左缘，并加大图标容器。

## 具体改动

### 改动摘要

搜索放大镜的圆和手柄都落在容器内部，左侧不再被裁切。

### 文件级变更

- **修改** `components/mark/index.wxss` — 放大镜画布改为 40rpx，圆环从左侧留出 4rpx
- **修改** `pages/home/index.wxss` — 首页搜索图标容器改为 40rpx
- **修改** `components/search-bar/index.wxss` — 搜索页图标容器同步为 40rpx

## 验证方式

放大预览里圆环是完整的，手柄从右下伸出。微信开发者工具需要重新编译。
