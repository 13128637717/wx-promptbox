## 背景与目标

「我的提示词」卡片右侧的编辑、删除文字要改成竖向三个点。点三个点后再选择编辑或删除。

## 方案概述

复用卡片上已有的更多按钮。我的提示词打开 `show-more`，点按后弹出「编辑」「删除」。编辑进入原编辑页，删除仍先确认，并同时去掉收藏。三个点改为在卡片右侧垂直居中。收藏页用的是同一个按钮，位置一起居中。

## 具体改动

### 改动摘要

去掉卡片上的编辑、删除文字，改为右侧三个点菜单。

### 文件级变更

- **修改** `pages/prompt/mine.wxml` — 打开 `show-more`，绑定 `more`
- **修改** `pages/prompt/mine.js` — `onMore` 弹出编辑、删除；删除确认后刷新列表
- **修改** `components/prompt-card/index.wxml` — 去掉编辑、删除文字列
- **修改** `components/prompt-card/index.js` — 去掉 `showManage` 及对应事件
- **修改** `components/prompt-card/index.wxss` — 三个点改为贴右并垂直居中

```24:36:pages/prompt/mine.js
  onMore(event) {
    const page = this
    const id = event.detail.id
    wx.showActionSheet({
      itemList: ['编辑', '删除'],
      success: function (res) {
        if (res.tapIndex === 0) {
          wx.navigateTo({ url: '/pages/prompt/edit?id=' + id })
          return
        }
        if (res.tapIndex === 1) page.confirmDelete(id)
      }
    })
  },
```

## 验证方式

按手机宽度预览了三张卡片：右侧是垂直居中的三个灰点，没有盖住标题和简介。菜单弹出和删除确认需要在微信开发者工具里点一次。

## 备注

首页、分类、搜索和详情推荐没有这个按钮。收藏页仍是「取消收藏」，只是三个点改到了垂直居中。
