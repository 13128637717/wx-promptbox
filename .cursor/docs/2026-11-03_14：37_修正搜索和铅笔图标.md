# 修正搜索和铅笔图标

| 项 | 值 |

| 概要 | 修正搜索和铅笔图标 |
| 关联计划 | 无 |

## 背景与目标

首页红框标出的两处图标不成形：搜索是断开的圆，写作创作是一条斜线。需要改成能认出的放大镜和铅笔。

## 方案概述

放大镜改为圆环加从右下缘伸出的手柄。铅笔改成同一组旋转的笔头、笔杆、空隙和橡皮。

## 具体改动

### 改动摘要

搜索图标和写作创作图标按完整轮廓重画，首页搜索图标略放大。

### 文件级变更

- **修改** `components/mark/index.wxml` — 铅笔拆成橡皮、空隙、笔杆、笔尖
- **修改** `components/mark/index.wxss` — 铅笔整组旋转 45 度；放大镜手柄从镜框边缘伸出
- **修改** `pages/home/index.wxss` — 搜索图标容器改为 36rpx

## 验证方式

放大预览中，铅笔能看出笔尖和橡皮，放大镜是完整的圆加手柄。微信开发者工具需要重新编译。
