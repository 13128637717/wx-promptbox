# 数据改为 JS 模块

## 背景与目标

关闭「过滤无依赖文件」后，模拟器仍报 `module 'data/categories.json.js' is not defined`。开发者工具会把 `require('*.json')` 编成 `*.json.js`，但没有生成对应模块。目标是让首页能加载分类和提示词数据。

## 方案概述

把 `data/` 下的 JSON 改成 `module.exports` 的 JS 文件，`utils/catalog.js` 改为 `require` 这些 `.js`。微信小程序对 JS 模块的依赖分析是稳定的，不再走 `.json.js` 这条路径。

## 具体改动

### 改动摘要

分类和各分类提示词从 JSON 改为 JS 模块导出，目录加载处同步改引用。

### 文件级变更

- **修改** `utils/catalog.js` — `require` 路径从 `../data/*.json`、`../data/prompts/*.json` 改为对应 `.js`
- **新增** `data/categories.js`、`data/prompts/*.js` — 原 JSON 内容前加 `module.exports =`
- **删除** `data/categories.json`、`data/prompts/*.json` — 避免继续被编成不存在的 `.json.js` 模块

## 验证方式

`node tests/catalog.test.js`、`prompt.test.js`、`search.test.js`、`export.test.js` 通过；`getCategories()` 为 10，`getSystemPrompts()` 为 180。需在微信开发者工具中重新编译，确认首页不再报 `categories.json.js is not defined`。
