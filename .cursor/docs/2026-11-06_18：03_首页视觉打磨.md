## 背景与目标

首页自定义导航只垫了状态栏高度。页面向下滚动后，分类第一行会钻进状态栏和右侧胶囊，发灰并且第四格被挡住。同时搜索、横幅和热门列表层次偏平。目标是固定顶栏、加强横幅和分类的对比，热度靠右，文案和跳转不变。

## 方案概述

1. `attachNav` 写入已有的 `navBarHeight`（状态栏 + 44px）
2. 首页标题固定在顶部，右侧留出胶囊宽度，滚动时用浅蓝底盖住内容
3. 搜索加细边框；横幅改为 `#1D4ED8` → `#3B82F6`，白字、浅底蓝字按钮
4. 分类色块改为 96rpx，标签 `#374151`，按下略压暗
5. 推荐卡片标题单行省略，热度排到元信息行右侧

## 具体改动

### 改动摘要

首页顶栏按胶囊高度固定，搜索、横幅和分类宫格拉开层次。推荐卡片标题单行显示，热度靠右，收藏和分类页沿用同一张卡片，结构不变。

### 文件级变更

- **修改** `utils/ui.js` — `attachNav` 同时写入 `statusBarHeight` 和 `navBarHeight`，其它页面仍只读状态栏高度
- **修改** `pages/home/index.js` — 默认 `navBarHeight` 为 64，首屏在取到系统信息前也不会贴到状态栏
- **修改** `pages/home/index.wxml` — 标题拆成固定顶栏，正文用 `navBarHeight` 让出顶栏；分类格子增加按压态
- **修改** `pages/home/index.wxss` — 顶栏固定并避开胶囊；搜索加边框；横幅改为饱和蓝；分类色块 96rpx、标签加深
- **修改** `components/prompt-card/index.wxml` — 标题包一层，便于单行省略，且「我的」仍紧挨标题
- **修改** `components/prompt-card/index.wxss` — 标题超出省略；热度和时间靠元信息行右侧

顶栏与正文的衔接：

```1:4:pages/home/index.wxml
<view class="topbar" style="padding-top: {{statusBarHeight}}px;">
  <view class="title">AI 提示词工具箱</view>
</view>
<view class="page home" style="padding-top: {{navBarHeight}}px;">
```

## 验证方式

`node tests/catalog.test.js`、`node tests/search.test.js` 通过。用同比例静态页核对了未滚动时的顶栏、横幅、八个分类和热度靠右、长标题省略。微信开发者工具未打开，模拟器里的固定顶栏和按压态需要重新编译后再看。

## 备注

收藏、分类、搜索、历史共用 `prompt-card`，热度或时间会靠右，卡片间距仍是原来的 20rpx。分类色、图标和跳转没有改。
