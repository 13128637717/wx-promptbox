# 分类页顶部固定

## 背景与目标

分类页右侧的条数、热度/最新和标签原先跟列表写在同一个纵向滚动区域里，下滑时会一起滚走。需要让这块停在列表上方，只滚动下面的提示词。

## 方案概述

右侧由整列 `scroll-view` 改成纵向 flex：工具条和标签留在滚动区外面，只有列表放进新的 `scroll-view`。列表用 `flex: 1; height: 0` 吃掉剩余高度，标签横向滚动单独给高度，避免在 flex 列里被压成 0。

## 具体改动

### 改动摘要

分类页右侧顶部（共 N 条、热度/最新、标签）固定，列表在其下方单独滚动。左侧分类栏仍独立滚动。

### 文件级变更

- **修改** `pages/category/index.wxml` — `.main` 改为普通容器；工具条和标签移出纵向滚动；列表包进 `.feed`
- **修改** `pages/category/index.wxss` — `.main` 改为纵向 flex；`.feed` 占满剩余高度；`.tags` 固定高度以免横向 `scroll-view` 塌缩

```12:30:pages/category/index.wxml
  <view class="main">
    <view class="toolbar">
      ...
    </view>
    <scroll-view class="chip-row tags" scroll-x wx:if="{{tags.length}}">
      ...
    </scroll-view>
    <scroll-view class="feed" scroll-y>
```

```70:74:pages/category/index.wxss
.feed {
  flex: 1;
  height: 0;
  min-height: 0;
}
```

## 验证方式

微信开发者工具打开分类页，列表较长时下滑：条数、热度和标签保持在右侧顶部；标签可横向滑动；切换分类、热度/最新和标签后列表仍在下方区域滚动。本次未在开发者工具里实机点选。

## 备注

标签行高度写成 `84rpx`（含原有上下内边距），用来撑开横向 `scroll-view`。若字号再变大，需要同步加高，否则标签会被裁切。
