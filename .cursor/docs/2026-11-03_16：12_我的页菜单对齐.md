## 背景与目标

「我的」页菜单右侧被裁掉，「意见反馈」和「分享给好友」整行偏到中间。目标是七行图标、文字、箭头左右对齐，条数和缓存大小完整显示。

## 方案概述

普通行补上 `box-sizing: border-box`，避免 `width: 100%` 再加左右内边距后被卡片 `overflow: hidden` 裁掉。意见反馈、分享给好友仍用原生 `button` 承接 `open-type`，但按钮本身只做点击层，排版放到内部 `view`，并用 `!important` 清掉按钮默认内边距、居中和行高。

## 具体改动

### 改动摘要

菜单行共用一份内容模板。普通行和按钮行都走同一套横向 flex，右侧条数、缓存大小和箭头不再被挤出卡片。

### 文件级变更

- **修改** `pages/profile/index.wxml` — 抽出 `menuBody` 模板；`open-type` 按钮改为透明点击层，内部用 `.row` 排版
- **修改** `pages/profile/index.wxss` — `.row` 使用 `border-box`；`.row-btn` 清掉原生按钮的内边距、居中和描边

```70:90:pages/profile/index.wxss
.row-btn {
  display: block !important;
  width: 100% !important;
  height: auto !important;
  margin: 0 !important;
  padding: 0 !important;
  border: none !important;
  border-radius: 0 !important;
  background: #ffffff !important;
  line-height: 1 !important;
  text-align: left !important;
  font-size: 0 !important;
  box-sizing: border-box !important;
  color: #1f2937;
  overflow: visible;
}
```

## 验证方式

用浏览器按 375px 宽预览同一套结构，并叠上微信按钮的默认内边距、居中和 `::after` 描边。七行图标左缘都在同一位置，箭头右缘都在同一位置，「0 条」和「1KB」落在箭头左侧。微信开发者工具需要重新编译后再看真机效果。
