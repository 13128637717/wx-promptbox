## 背景与目标

我的提示词列表右侧没有操作入口。需要和收藏列表一样，在卡片右侧提供操作，并能编辑或删除自己的提示词。

## 方案概述

复用提示词卡片已有的右侧三点按钮。点击后弹出操作列表，第一项进入编辑页，第二项沿用原来的删除确认。

## 具体改动

### 改动摘要

我的提示词每条卡片右侧显示三点，点开可选编辑或删除。

### 文件级变更

- **修改** `pages/prompt/mine.wxml` — 卡片打开 `show-more`，点击三点交给 `onMore`
- **修改** `pages/prompt/mine.js` — `onMore` 弹出「编辑」「删除」；编辑进入编辑页，删除仍先确认再移除提示词和收藏

```24:38:pages/prompt/mine.js
  onMore(event) {
    const page = this
    const id = event.detail.id
    wx.showActionSheet({
      itemList: ['编辑', '删除'],
      success: function (res) {
        if (res.tapIndex === 0) {
          page.onEdit({ detail: { id: id } })
          return
        }
        if (res.tapIndex === 1) {
          page.onDelete({ detail: { id: id } })
        }
      }
    })
  },
```

## 验证方式

微信开发者工具重新编译后，打开我的提示词：卡片右侧有三点；点编辑进入编辑页；点删除会出现确认框，确认后该条从列表消失。

## 备注

收藏页的三点仍只有「取消收藏」。点卡片主体仍进入详情。
