## 背景与目标

按需求文档和界面合集，做一款不登录、不连服务器、不调用大模型的微信小程序。用户可以浏览 10 个分类下的提示词，搜索、收藏、复制，用本地模板填写变量后生成正文，并管理自己的提示词和备份。

## 方案概述

1. 原生小程序放在仓库根目录，内置 JSON 只读，用户数据进本地存储。
2. 首页只放 7 个分类入口，自媒体、商业运营、数据分析从全部分类进入。
3. 创建页把需求填进模板的「主题」，缺必填项时进入变量编辑器；生成结果可改、可复制、可保存。
4. 导入先校验再合并，失败或写入异常时保留原数据。不做分享海报、版本对比、付费和自定义收藏夹。

```55:65:utils/prompt.js
function applyVariables(content, fields, values) {
  const map = {}
  const missing = []
  ;(fields || []).forEach(function (field) {
    const resolved = resolveValue(field, values ? values[field.name] : '')
    if (!resolved.ok) missing.push(field)
    else map[field.name] = resolved.value
  })
  if (missing.length) {
    return { ok: false, missing: missing, text: String(content || '') }
  }
```
