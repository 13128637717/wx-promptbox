# 分类页底部不再被截断

| 项 | 值 |
|----|-----|
| 日期 | 2026-11-03 |
| 时间 | 14:45 |
| 概要 | 分类页底部不再被截断 |
| 关联计划 | 无 |

## 背景与目标

分类页是底部栏页面，高度用 `100vh` 减去一段固定值，区域会伸进底部栏下面，左侧分类和右侧列表的最后一项被挡住。

## 方案概述

布局改为贴住导航栏和底部栏之间的可见区域，左右滚动区限制在这个高度里，滚到末尾时最后一项留在底部栏上方。

## 具体改动

### 改动摘要

分类页不再用 `100vh` 估算高度，左右列表都在底部栏之上完整滚动。

### 文件级变更

- **修改** `pages/category/index.wxss` — `.layout` 改为 `top/right/bottom/left: 0`，并限制滚动区最小高度
- **修改** `pages/category/index.wxml` — 左侧分类列表底部加一段空白，最后一项不贴边

```1:10:pages/category/index.wxss
.layout {
  position: fixed;
  top: 0;
  right: 0;
  bottom: 0;
  left: 0;
  display: flex;
  overflow: hidden;
  background: #f7f8fa;
}
```

## 验证方式

微信开发者工具重新编译后，打开分类页，把左侧分类和右侧提示词都滚到最底，最后一项应完整出现在底部栏上方。
