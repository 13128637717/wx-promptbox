# 详情页编辑删除布局

| 关联计划 | 无 |

## 背景与目标

自己的提示词在详情页里，编辑和删除是贴在右下角的两行小字，挤在「调用记录」下方。需要改成容易点到、和页面其它按钮对齐的布局。

## 方案概述

只在自己的提示词上显示这两个操作。收藏、分享、调用记录三列不动。编辑和删除改成并排的两个圆角按钮，各占一半宽度，放在三列操作的下一行。编辑保持蓝色，删除保持红色。

## 具体改动

### 改动摘要

详情页自己的提示词不再用右对齐文字链，改为等宽的编辑、删除按钮。

### 文件级变更

- **修改** `pages/prompt/detail.wxml` — `user-ops` 内的两个 `text` 换成可点击的 `view`，仍分别绑定 `onEdit`、`onDelete`
- **修改** `pages/prompt/detail.wxss` — 去掉右对齐和文字间距，两个按钮横向平分、圆角描边

```54:57:pages/prompt/detail.wxml
    <view class="user-ops" wx:if="{{isUser}}">
      <view class="user-op" bindtap="onEdit">编辑</view>
      <view class="user-op danger" bindtap="onDelete">删除</view>
    </view>
```

## 验证方式

按详情页尺寸做了静态预览：复制按钮下方仍是收藏、分享、调用记录三列，再下一行是等宽的编辑和删除。微信开发者工具需要重新编译后，用自己的提示词打开详情页确认点击。

## 备注

内置提示词没有这两个按钮。跳转和删除确认逻辑未改。
