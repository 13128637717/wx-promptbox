## 背景与目标

提示词详情页头部把描述挤在图标右侧，操作区是一条白底分段文字栏。收藏页顶部还有搜索框，列表卡片会画出描述，也没有取消收藏的入口。按已通过评审的计划，把这两页的版式和操作对齐设计稿，并给收藏卡片加一个默认关闭的更多菜单。

## 方案概述

1. `mark` 用现有纯 CSS 补 star、share、clock；star 增加默认关闭的 `solid`，未收藏空心、已收藏实心。
2. 详情头部改为图标与标题同行，分类胶囊和人气在标题正下方、仍在图标右侧，描述作为整行的下一个兄弟通栏排在下面。内容区改为浅灰圆角块，操作为三枚圆形按钮，相关推荐只传 `brief`。
3. 收藏页去掉搜索框和 keyword 过滤，列表使用 `brief` 并打开 `show-more`。更多菜单只有「取消收藏」，确认后调用 `storage.removeFavorite`。
4. `prompt-card` 的 `showMore` 默认 false，不传时不渲染更多、不加右侧内边距。

## 具体改动

### 改动摘要

详情白卡按设计稿重排，收藏页改为无搜索的 brief 列表，并只在这一页打开卡片右上角的取消收藏菜单。首页、分类、搜索、数据层和 tabBar 未改。

### 文件级变更

- **修改** `components/mark/index.js` — 增加 `solid`，Boolean，默认 `false`；`name`、`ink` 默认值不变
- **修改** `components/mark/index.wxml` — 在四格 grid 回退前增加 star、share、clock；空心星才渲染白色内层遮罩
- **修改** `components/mark/index.wxss` — 五角星用 `clip-path` 和 `currentColor`，分享为线框方盒加向右上箭头，时钟为圆形描边加两根以底部为原点的指针
- **修改** `pages/prompt/detail.wxml` — 头部按图标行 / 通栏描述重排；内容去掉 `card`；收藏、分享、调用记录改为三枚圆按钮；相关推荐传 `brief`，不传 `show-more`
- **修改** `pages/prompt/detail.wxss` — `.head` 改为块级，描述 `margin-top: 20rpx` 通栏；内容区背景 `#eef0f4`；去掉白底通栏操作条
- **修改** `pages/favorite/index.wxml` — 删除搜索框；分类芯片仍为页面第一块；列表 `brief` + `show-more`，并绑定 `more`
- **修改** `pages/favorite/index.js` — 删除 keyword 与 `utils/search.js`；`apply` 只按分类过滤；`onMore` 弹出仅含「取消收藏」的菜单
- **修改** `pages/favorite/index.wxss` — `.cats` 改为 `margin: 0 0 20rpx`，本页芯片收紧间距；选中态仍用全局 `.chip.on`
- **修改** `components/prompt-card/index.js` — 增加默认 `false` 的 `showMore`；`onMore` 只抛出 `more`
- **修改** `components/prompt-card/index.wxml` — `showMore` 为真时右上角渲染竖向三点，`catchtap` 不触发 `select`
- **修改** `components/prompt-card/index.wxss` — `.item` 仅 `position: relative`；右内边距只加在 `.body.has-more`

收藏更多菜单用页面自身的 `this` 刷新列表，取消菜单时不改列表：

```38:49:pages/favorite/index.js
  onMore(event) {
    const page = this
    const id = event.detail.id
    wx.showActionSheet({
      itemList: ['取消收藏'],
      success: function (res) {
        if (res.tapIndex !== 0) return
        storage.removeFavorite(id)
        wx.showToast({ title: '已取消收藏', icon: 'none' })
        page.apply(page.data.categoryId)
      }
    })
  }
```
